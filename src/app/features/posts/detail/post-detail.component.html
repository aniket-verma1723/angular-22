Independent comments, dependent author

Concept: comments start with the post; the author starts only after a validated post provides userId.

Try it: retry comments or the author independently, then open a different post.

Angular mechanism: an inner switchMap follows the author dependency. Route-scoped shareReplay shares one post read between rendering and the author stream.

Common mistake: subscribing twice to cold HTTP, nesting subscriptions, or rendering API text as HTML.

Revision prompt: what is cancelled when the route ID changes, and when is the shared cache discarded?
