Compare the form contracts

P05 binds a Signal Forms field tree. Here, typed FormGroup/FormArray controls own the draft. The delivery ControlValueAccessor receives writeValue/setDisabledState and reports change/touched without echoing programmatic writes. P04's quantity model is a component binding, not a form control.

Review reads getRawValue() so disabled values are explicit. No parallel writable signal model, address storage or automatic write retry is used. Leaving discards the form; the cart survives unless a matching submission succeeds.
