M00–M07 · Foundation through public tasks

Your workspace is taking shape.

Browse products, build an anonymous cart and sign in for simulated checkout or local demo-admin editing. Session guards are navigation UX, not server authorization.

Public users, profiles, posts and comments retain their recorded verification. Public paged task CRUD, the bounded write queue and native local ordering retain their P08 verification; P10 adds snapshot-validated same-column pointer drag/drop.

P08 dashboard widgets and nine local RxJS recipes are implemented and verified within the recorded scope. No API requests are made before you select Load widgets; the RxJS recipes run locally.

P09 core labs are delivered: components, DI, state, routing, four resource readers and three forms comparisons. Advanced and awareness lessons remain separate; this is not full curriculum completion.

P10 adds three lazy labs: Material interactions and a complete local table, independent Signal single-date and Reactive range/time fixtures, and owned CDK overlay, virtual selection and utilities. Inputs are local experiments, not saved settings.

P11 full follow-up delivers animation, profiling and image lessons alongside defer and opt-in preloading. Explore reduced-motion cleanup, method versus computed work and reserved fill-image fallbacks. Selected local tools are configured: ESLint, Playwright, axe, bundle auditing and browser measurements. This is not full curriculum completion or accessibility, security or performance certification.

P12 enables zoneless application scheduling. The notification lab compares signals with markForCheck, including callback cancellation and cleanup. Zone.js remains test-only; Eager and OnPush are checking strategies, not schedulers.

Tasks are public: assignment and user filters are not session identity. Profile task links open the board, not a nested tab. Drag and native Move up/down send no HTTP for order; Completed still uses the PATCH queue. CDK does not supply keyboard dragging.
