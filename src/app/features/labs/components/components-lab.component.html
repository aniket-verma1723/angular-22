P09 · Framework experiments

Components lab

Predict, interact, observe, then revise. Seven small experiments fill the component catalogue gaps without rebuilding the store. Each card owns local fixtures; nothing sends HTTP or changes your cart or session.

Optional widgets, shadow samples and render probes are created only on request. Leaving resets this lab. The existing root stays Eager; these components use Angular 22’s default OnPush. Both checking strategies are independent of P12’s zoneless application scheduling.
