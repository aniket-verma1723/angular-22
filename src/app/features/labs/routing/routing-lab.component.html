Nested navigation, guards and resolvers · R01–R07/R11

Concept

These are real nested lazy routes with local fixtures. A resolver blocks activation; the already-active parent keeps the experiment controls available.

Try it

Select Controlled, open the other notebook, then complete or fail the pending resolver. Toggle permissions before trying a new URL.

What Angular does

canActivateChild gates workspace descendants; canMatch gates matching. ID validation precedes the resolver. Guards return redirect trees, and resolver errors return RedirectCommand to local recovery. pathParamsOrQueryParamsChange reruns the resolver for ID or query changes, but not fragment-only changes. The optional departure checkbox exercises functional canDeactivate without a modal.

withComponentInputBinding (already configured in this app) binds the actual detail's path ID, query revision and resolved fixture to input signals. Input transforms validate unknown values; the ID guard rejects invalid paths before resolution. Missing, duplicate or invalid revisions fall back to 1. ActivatedRoute remains only for title and fragment observations; there is no duplicate writable URL model.

Common mistake

These switches are local learning permissions, not authentication or server authorization. A missing fixture is not an unknown route. Do not wait for a noncritical widget in a resolver.

Revision question

Which view remains interactive while a child resolver is pending? Why does the recovery route sit outside the guarded workspace?

Test observation: harness specs exercise completion/error/cancellation, redirects, invalid IDs, query reruns and departure blocking with no HTTP.

Named outlets, matching and default reuse · R10

Concept

A named outlet can coexist with the primary route. Default reuse retains a component for the same route configuration with different parameters.

Try it

Type a local note, switch IDs and compare the instance number. Open help, close it, then leave the notebook and return.

What Angular does

The custom matcher accepts exactly recipe/signals or recipe/di without matrix parameters. Closing help removes only the named outlet and restores its control focus. Detail DestroyRef and toSignal subscriptions end on departure, not an ID change.

Common mistake

No custom reuse cache exists here. Route configuration injectors can persist beyond a component. Parent-view departure cancels active work and resets interactive permissions and resolver mode, so revisiting cannot block before the controls appear. Child parameter changes preserve configuration.

Revision question

Concept

URLs carry shareable path/query/fragment state; navigation extras belong to a history entry. The default title strategy selects the deepest primary route title.

Try it

What Angular does

The component observes at most twelve event IDs/types with destruction-bound teardown, never logs arbitrary URLs or state objects. Existing application scrolling handles anchors and history positions; local tests isolate the router and mock history. Pixel scroll restoration remains a browser check, not implied by URL tests.

Common mistake

Do not preload every advanced lab. This feature installs neither a global preload strategy nor view transitions. View transitions are developer preview in the installed declarations; reduced-motion-aware comparison and performance measurements remain optional P11 work.
