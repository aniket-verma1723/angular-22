Concept

Resources combine asynchronous reads with synchronous signal views. HttpClient + RxJS offers explicit stream composition; httpResource is HTTP-specific; rxResource adapts observables; resource uses a promise or async loader.

All four validate the same unknown product detail and expected ID, omit credentials, disable transfer cache, and bound reads to 15 seconds. No null product is treated as a successful empty result.

Resource value reads are guarded by hasValue(). New IDs clear the prior value; same-ID reload retains it with a stale label until the new read resolves. Repeated same-ID actions while busy do not overlap. Clear cancels the pending read and returns to idle. Destroying the active view cancels its work.

Common mistake

{{ lesson().mistake }}

Reactive loaders are not durable write queues. Cancellation does not prove server rollback, and locally setting a resource value would not persist a product. This lab offers reads only.
