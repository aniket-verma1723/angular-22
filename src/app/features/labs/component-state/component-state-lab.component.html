Concept

State belongs to an owner. A model connects a child control to its parent's signal; projection lets the caller supply content; a component provider shares state only inside its experiment.

Angular mechanism

  • model() creates a writable input and its matching change output. [(quantity)]="draftQuantity" binds the signal itself, not its current value.
  • ng-content selects [lesson-title] and [lesson-actions]; unmatched content goes into the default slot. Fallback content appears for empty slots.
  • providers: [LabCounter] gives each experiment one injectable instance. Both probes call inject(LabCounter) and resolve their nearest owner.
  • OnInit registers a probe and OnDestroy unregisters it. A later sibling observation view reads the service's signals after probe hooks, not through a synchronous parent hook binding.
  • computed() derives the active-probe count. Read-only signals expose observations; semantic methods own writes. Angular's default OnPush tracks these signal reads.
  • In the catalogue, ProductCardComponent receives required product inputs and emits add intent; the parent calls the root cart service. The card never owns a second cart.
  • StockLevelDirective uses host metadata for emphasis while stock text remains readable. The pure UsdCentsPipe formats derived cart amounts; it does not calculate or change prices.

Common mistake

Providing the counter on each probe would split sibling state. Providing it at root would accidentally share both experiments. Copying derived values with effects adds a second writable source of truth.

Do not synchronously change a checked parent binding from a child's initialization hook. A timer or manual change detection would hide the ownership problem rather than solve it.

Revision question

Why does hiding both probes preserve the count, but destroying their experiment resets it? Which provider scope would make the two experiments share a count?

Test observation

Expect both siblings to display the same count, the independent experiment to stay unchanged, and active probes to move between two and zero. The bounded log retains only the last 12 lifecycle events.

Counters intentionally live only for the experiment's lifetime. Recreating the page also resets the draft quantity. The application's root cart service, in contrast, persists across route navigation within the same application session. This lab never injects or updates that cart.
