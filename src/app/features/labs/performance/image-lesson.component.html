Concept

NgOptimizedImage fill mode sizes an image to its positioned parent, not its intrinsic dimensions. This optional, below-the-fold image is lazy and not priority.

What Angular does

The directive sets lazy loading and absolute fill positioning. The parent reserves space with position: relative and aspect-ratio: 16 / 9, capped at 32 rem. The responsive sizes hint allows for narrow-page gutters; Angular can prepend auto for the actual rendered width. This local SVG has no resizing CDN or generated responsive variants; sizes alone does not reduce its transferred bytes.

Common mistake

Fill does not reserve height on its own. Do not add conflicting width/height attributes or mark every image priority. Both the image and named fallback occupy the same frame; a failed request does not collapse it. Restore creates a fresh image even for the same URL.
