What Angular does

The standalone summary appears only inside defer blocks. The compiler can split its import; prefetch fetches code without creating the component. Loading appears after 100 ms and, if shown, remains for at least 200 ms. Fast loads may skip it; no artificial download delay is added.

The workbench reserves representative desktop/narrow summary space to reduce expansion. Enlarged text can still grow it; reserved space is not a guarantee of zero layout shift.

Common mistake

All seven blocks deliberately reuse one payload. Once loaded, its JavaScript module is cached: later triggers can create new instances without a new download. Unmounting does not clear that cache. A class query or eager use in this entry would defeat deferral eligibility.

Revision question

Why can prefetch download code with zero instances? Why does closing a completed signal gate leave the summary visible, while unmounting destroys it?

Route lazy loading versus preloading

Concept

Separate lazy route components move the loading boundary to navigation. Preloading can fetch an opted-in route before navigation without creating its component.

Try it

In a fresh production-like page, visit this lab before either child. Compare the two links in the Network panel, then navigate between them again. No child opens automatically.

Load on demand Open preload candidate

What Angular does

Each child uses its own dynamic import. Only the preloaded child has data: { performancePreload: true }. The application owns the global preloading strategy; metadata alone does nothing. With the containing lab left unpreloaded, these children are discovered only after the lab is visited.

Common mistake

Do not equate preloading with activation or promise a speed gain from these small fixtures. An already cached module can hide both route and defer downloads. HMR can eagerly fetch defer chunks; use production output or disable HMR for trigger observations.

Revision question

What changes if the global strategy ignores the opt-in, preloads everything, or never runs?

Test observation

Local router tests verify lazy child selection and no default child. Production artifact and browser Resource Timing/Performance observations belong to the integration pass. Record cold and repeat visits, transfer sizes and LCP/INP/CLS separately; no global observer runs here.
