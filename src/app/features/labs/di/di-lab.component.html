What Angular does

The environment initializer starts a local 150 ms configuration fixture; the 600 ms deadline and injector destruction end pending work. It is not an app bootstrap initializer. Element hierarchy and projection · D03/D04

Concept

Element providers and environment providers form distinct hierarchies. Projection keeps the declaring view's visibility.

Try it

Compare the same probe in the panel view and in projected content. Increment either shared component counter, remove the panel and recreate it. Predict self + optional before inspecting null.

@if (scopes()) { }

What Angular does

self finds child; skipSelf finds component. Both children share the panel counter, but only the panel's own view sees panel-view. The projected child sees parent-view. host stops at the declaring component's host boundary: the panel view cannot reach outer-only with host, while the projected child can. optional returns null rather than throwing. Removing the panel destroys its counter; recreation starts at zero.

Common mistake

viewProviders is not a security boundary. Root services normally outlive components; route providers are scoped to route configuration, not a promise of destruction on every navigation. Component providers are destroyed with their view.

Revision question

Why does moving content into ng-content not give it the panel's private view provider?

Test observation: rendered probes assert actual self/skipSelf/host/optional values and projection visibility.

Async DI awareness · D07

Concept

Installed Angular 22.1.7 declares injectAsync as public API 22.0, not experimental; it is an advanced lazy-service contract, not permission to call inject after await.

Try it

Run the context probe above, then compare its captured dependency with a lazy loader returning a promise.

What Angular does

injectAsync(loader, options?) returns a function returning Promise<T>. Lazy services must be auto-provided with Service or Injectable providedIn root. Here Injectable without a root scope makes ownership explicit. Constructor DI remains valid for legacy comparison; field inject captures the same dependency during construction.

Common mistake

Async DI is not an async injection context. No lazy-service runtime or prefetch is installed for this awareness-only exercise.

Revision question

Which function is created in the injection context and which function may be awaited later?
