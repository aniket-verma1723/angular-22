Read the URL, not a second store

Concept: the URL owns the committed query; a linked signal owns the draft.

Try it: type a name, change page size, open a profile, then go Back.

Angular mechanism: toSignal renders a switchMap read; newer queries cancel older requests.

Common mistake: filtering only the current server page or allowing an old debounce to navigate later.
